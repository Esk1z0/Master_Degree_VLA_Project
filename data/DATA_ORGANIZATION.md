# Data Directory

This directory contains static datasets, experiment configuration layouts, and raw camera calibration images for the project.

## Structure

```
data/
├── camera_calibration/         # Stereo camera calibration sessions & sample outputs
│   ├── session_1_20260428/     # Raw initial capture session (30 images)
│   ├── session_2_20260505/     # Raw intermediate capture session (23 images)
│   ├── session_3_active/       # Active stereo calibration set (26 images: photo_1..photo_24 + extra)
│   └── samples/                # Sample rectified stereo & depth map images
│       ├── original_image.png
│       └── depth_image.png
│
└── layouts/                    # Balanced workspace episode layout definitions
    ├── so101_layouts_001_060.csv
    ├── so101_layouts_061_120.csv
    ├── so101_layouts_121_180.csv
    ├── so101_layouts_181_240.csv
    └── so101_layouts_skip_block.csv
```

## Descriptions

### 1. `camera_calibration/`
Stores dual USB camera calibration images captured with the 9x6 inner corner chessboard pattern (40.5 mm squares).
- **`session_3_active/`** is the primary image dataset processed by [`camera/stereo_calibration.py`](../camera/stereo_calibration.py) and [`camera/calibracion_camara.ipynb`](../camera/calibracion_camara.ipynb) to compute the stereo calibration matrices ($K_L, K_R, D_L, D_R, R, T, Q$).
- **`samples/`** contains sample full-resolution stereo captures and generated depth maps for visualization.

### 2. `layouts/`
CSV files generated by [`ablation/combinations.py`](../ablation/combinations.py) defining 240 randomized and balanced physical block/star object arrangements and rotations across discrete workspace zones (`A1` to `C3`), plus a 60-episode skip-block batch. Used during physical robot evaluation on the SO-101 arm.
